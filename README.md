# ReverbRift

Networked interactive audio engine for real-time dynamic sound rendering on scalable system platforms.

With ReverbRift, you get a lightweight tool that stays out of your way.

**What you get**

- Networked interactive audio engine for
- real-time dynamic sound rendering on
- scalable system platforms

## Key Features

- Networked interactive audio engine for
- real-time dynamic sound rendering on
- scalable system platforms

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/ReverbRift.git`
2. `cd ReverbRift`
3. Install in editable mode: `pip install -e .`

## Configuration

ReverbRift is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
